# Homs FTTH / wireless network planner

Web planner for fibre (GPON), wireless (PTP/PTMP) and mixed networks, locked to Homs governorate.
Real 3D building footprints, house numbering, material prices and automatic cost, AutoCAD (DXF) export of a chosen area.
Open it from a computer (phones are not supported).

Data credits: building footprints © Microsoft (ODbL); map data © OpenStreetMap contributors (ODbL); basemap OpenFreeMap / OpenMapTiles; terrain: AWS Terrain Tiles; satellite option: Esri.
