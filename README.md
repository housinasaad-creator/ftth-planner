# Homs FTTH / wireless network planner

Web planner for fibre (GPON), wireless (PTP/PTMP) and mixed networks, locked to Homs governorate.
Real 3D building footprints, house numbering, material prices and automatic cost, AutoCAD (DXF) export of a chosen area.
Network model and exports follow the Syrian Telecom (ST) FTTH micro-trenching specification: FDC / FDB naming, total split <= 1:16 in two stages, one FDB per building, loss <= 28 dB, HH/MH spacing <= 250 m, official box codes, compliance check (SOC), GeoPackage / KMZ / LLD / OTDR template / 100 m trench sections.
Editing: building handles (stretch in 4 directions, move, corners, merge, delete with automatic renumbering), imported KML/KMZ files are locked until unlocked (then every point can be moved), drag to reorder layers, middle mouse button + drag rotates the camera.
Fibre engineering: strand-by-strand trace, splice tables, optical signal budget, splitter ratio badges, subscriber ports, PON tree, wireless coverage.
Delivery: one-click PDF report, self-explaining Google Earth (KMZ) export, editable AutoCAD drawing with houses; prices in USD, EUR or SAR.
Team: live shared projects, and an upload button that reports "saved" only after the server confirms it.
Learning: a "Tutorials" button with video lessons (Arabic and English), tips and shortcuts, and an interactive training on a sealed practice project.
Open it from a computer (phones are not supported).
